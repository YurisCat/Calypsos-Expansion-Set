# 2026-10-23 游戏更新兼容排查

0.2.78 修复两处已确认的接口变化及加载失败后的残留回调。十五种雕像与公共模块均已核对当前游戏接口；未发现其他直接接口失配。以下区分接口／资源研究、托管检查与真实运行日志，不作为全功能实机验收。

## 更新变化与修复

| 变化 | 证据与处理 |
| --- | --- |
| 冲刺输入改名 | `OnRunInput_ContinuousState` 删除，改为 `OnRunInput`；原版增加跑步模式及跳跃后恢复处理。极速补丁改接新入口，保留原动作资格 |
| 调试自由相机实现移除 | `CliSetFreeCamWorldRig` 及状态字段删除，`NoClipCamController` 只余构造，遗留 `UseFreeCamWorldRig` getter 原生恒 false；不能只换 setter 名 |
| 正常第三人称显示保留 | `CliDisplayThirdPersonRig(bool)` 仍更新本地／世界模型及持物显示。新共用 `LocalWorldRigView` 绑定具体角色、模型与所有者；原版换装等直接调用静态 `DisplayThirdPersonRigState` 时让出所有权，清理不覆盖接管者 |
| 部分加载后的持续错误 | Harmony 遇到坏目标前已装部分渲染补丁。增加安装／驱动创建失败回滚：先撤销自有补丁，再释放服务，保留原始异常并清空全局引用 |
| 网络恢复与其他更新 | 新增 `Mirror.ResumableTransport`、恢复状态和通知；另有骰子权重、棋盘调试 setter、音频／EOS 包装变化。核对 MOD 实际调用，未发现其他缺失引用，不据此改写玩法或协议 |

最初 0.2.77 日志有 **1,302 条 Error**：一次加载失败、650 次检查视角停止、651 次检查清理失败。后两类重复报告缺失的相机 setter，数量不代表独立根因数量。
