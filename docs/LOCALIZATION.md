# 游戏内本地化

## 覆盖范围

0.2.64 起，正常游戏中的自有文案支持英语、简体中文、繁体中文、日语、俄语、巴西葡萄牙语和西班牙语。语言跟随每个客户端自己的游戏设置，无新增 CFG。

| 文案 | 来源与范围 |
| --- | --- |
| 雕像名称与箴言 | 原版 21 条、当前 MOD 15 条；终局雕像和缺失拼图只提供箴言，名称继续使用原版译文 |
| MOD 统一名称 | 名称开关关闭时使用当前语言的统一名称；原版仍保留原名 |
| 大厅盒子 | 名称、查看介绍、关闭、滚动提示、打开后的完整正文 |
| 制作人员 | 标题与职责翻译；中文语言保留已确认中文昵称，其余语言使用已有拉丁字母昵称，昵称不作意译 |

F8 调试界面、测试房专用标签、CFG 注释、README 和 N 网介绍不纳入这次七语言翻译。盒子编辑器、补光列表等调试文案保持原有中英选择。原版其他界面及外部 MOD 的自有文字不由本功能翻译。

## 文案来源与风格

- 简中 MOD 文案继续来自各类型定义，原版对照来自 `UI/OriginalIdolAdvice.cs`；已经确认的简中、英文名称、箴言及盒子正文保持。
- 英文雕像表保留在 `UI/IdolTextLocalization.cs`，供原有本地图鉴读取。新增五种语言在 `UI/IdolTextTranslations.cs`；盒子及职责在 `Lobby/LobbyBoxText.cs`。
- 简中和繁中保留四字双句及原有趣味。日语使用拟声、对称短句和自然节奏；俄语、葡语、西语尽量使用押韵双句。先保持玩法含义，不为押韵追加能力、伤害、免疫、生成或寻敌保证。
- 翻译同时参考已确认中英文、类型源码和本地图鉴简介。例如接力需要换人、疑神的假声可能引来真怪、怪相不获得怪物能力；箴言不是完整操作说明。
- 所有箴言为单行、不超过 80 个 UTF-16 字符。字符数只约束文本长度，实际宽度由字体和显示区域决定。
- 盒子介绍与操作提示使用自然说明语气，保留欢迎语、玩法介绍、四条生活质量说明及结尾，不写成版本日志。

## 语言选择和身份隔离

`UI/UiLanguage.cs` 将 I2 语言代码映射为内部枚举。本机当前资源中的对应代码为 `en`、`zh-CN`、`zh-TW`、`ja`、`ru`、`pt-BR`、`es`。接受大小写、下划线及常见地区／文字变体；葡语地区变体共用巴西葡语稿，西语地区变体共用当前西语稿。

只有代码缺失或为空白时才读取 I2 语言名称，包含当前资源的 `Simplified_chinese`、`Traditional_chinese` 和 `Portuguese_brazil`。未知／尚无翻译的语言回退英文；语言源读取失败时保留上次成功选择，记录一次警告并重试。未初始化时使用英文。

选择保存在本机 `IdolHoverInfo` 实例中，每半秒最多采样一次；盒子共享该缓存，在各自显示更新周期刷新。交互 getter 不封送 I2 字符串，不查询系统区域，不订阅全局语言事件，也不向 I2 数据源写入词条。

雕像译文仍先核对实际配置 ID、稳定 key 和原版／MOD 身份。注册定义优先、空说明 opt-out、未知外部内容及原版未指定名称保持原有处理。译文表不决定注册状态。名称开关、箴言开关及怪相持有期间隐藏提示的优先级保持。

本次只改变本机显示，不改协议、内容清单、配置 ID、assetId 或各类型 ContentVersion。

## 字体、布局与生命周期

- 雕像顶部箴言继续跟随原版当前消息字体／材质和消息避让规则。
- 盒子阅读时按原有短周期获取当前角色的原版字幕字体；字体、字号或样式变化时刷新自有正文、滚动提示和署名，并重新计算换行及滚动范围。语言变化回到顶部，清除旧滚轮样本，移动输入先回中立再重新接受。
- 制作人员使用实际文字度量同时检查高度和整行宽度；两位开发者、职责与图标共同参与宽度计算。操作及滚动提示采用有下限的自动字号。
- 字体、材质与输入图标仍借用原版资源，不修改共享字体、不捆绑额外字体或网络组件。原有淡出、关闭、失效源、断线、角色与场景更换清理保持。

## 验证边界

0.2.64 完成当前游戏语言资源只读研究、Release 编译及链接实际 UI 源码的托管检查；完整证据见 [DEVELOPMENT](../DEVELOPMENT.md) 的对应版本记录。托管字体度量为替身，不能证明原生字形覆盖、实际换行、渲染或设备操作通过。

需要游戏内覆盖七种语言往返切换、同一指向目标、盒子打开期间的切换与重新打开、不同屏幕比例、名称／箴言开关、怪相持有隐藏、长名称、制作人员与图标位置，以及正常消息／菜单和生命周期边界。多人各自语言、观察者、晚加入与重连另验。译文已按机制进行编辑核对，尚未经过独立母语者审校。
