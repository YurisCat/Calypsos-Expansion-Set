# 大厅盒子与摆放工具

大厅中的桌游盒子是固定展示物，每个客户端创建自己的视觉对象。安装 MOD 的玩家可独立查看介绍；它不能拾取、推动或出售。名称、完整介绍、交互／滚动提示及制作人员职责支持英、简中、繁中、日、俄、葡、西七种语言，随本机游戏语言切换；简中和英文正文沿用确认文本。其他语言回退英文，范围及地区约定见 [本地化说明](LOCALIZATION.md)。

“游戏性提升”介绍新雕像与骰子伪装诅咒，采用“骰子会带来新的诅咒：你会变成其他人。大师棋盘也有几率出现该规则。”，七种语言保持同等含义。该条按确认原文保留，不追加获取提示等界面惯例。“生活质量提升”中英各四条：棋盘玩家棋子碰撞、雕像箴言与可选名称、初始房名字颜色提示、商店体力。箴言与名称合并说明，两项可分别配置，具体名称默认关闭；名字提示采用“在大厅时，头像名字变为青色”，其余情况保持原色。商店体力沿用现有简短提示。欢迎语、结尾及原有项目符号保持，不加入版本日志或同步实现细节。

## 交互与摆放

靠近盒子时显示原版样式的交互点，瞄准后显示名称与交互提示。键盘默认 E，沿用原版统一交互输入和按键／手柄图标资源，支持改键。按下后进入原版检查物品相机：盒子位于画面右侧，左侧显示当前语言介绍。镜头到位后才接受再次按交互键关闭，并在屏幕右下角附近显示当前语言的“关闭”和原版绑定图标；拉近期间的交互按下／释放由本功能消费，不提前关闭或转交给世界物体。查看期间暂停角色移动和转向，不需要继续瞄准盒子；打开前仍显示名称与当前语言的“查看介绍”。

左侧背景借用原版书本 `SubtitleUI/BackgroundGradient` 的横向黑色渐变，仅水平翻转背景对象；文字正常朝向，原版全屏边缘暗角保持。自有屏幕 UI 重新创建 Image/TMP，使用原版字体及其图集，不克隆运行中控件，不修改原版字幕或本地化条目。正文字号为原版参考的 80%，阅读区按屏幕比例留出顶部 HUD 空间、屏幕边距、下方署名及右侧盒子的间隔；原版 HUD 和重要消息绘制在介绍之上。

正文过长时只在阅读区内滚动，超出区域的文字被裁切。滚轮每格立即移动两行，可连续滚动；也可使用当前绑定的移动键（默认 W/S）或手柄摇杆连续上下滚动。进入时先松开移动键／让摇杆回中立，镜头到位后才接受滚动；滚轮用于正文时不切换库存物品。上下边界限制在内容范围内，重新打开或切换语言回到顶部；正文放得下时隐藏滚动提示。

制作人员固定在正文下方，使用较小字号：标题偏金色、职责灰色、昵称浅色，不跟随正文移动。职责按七种语言翻译，昵称不带 @；简繁中文使用现有中文昵称，其余语言使用现有拉丁字母昵称，不自行翻译署名。适用的 B 站图标放在昵称后：中文开发署名显示图标，其他语言开发署名不显示，其他语言的模型制作者 Tomato_Fish 显示图标。按文字实际高度及整行宽度适配字号，计入两位开发者、职责与图标。各语言介绍保留欢迎语和原有条目结构，不包含临时滚动测试段落。

取景依据模型变换后的八个包围盒角点、原版检查相机镜头和当前屏幕比例计算，盒子中心目标为屏幕横向 75%、纵向 50%，边界留有余量；不移动大厅中的盒子。进入查看或分辨率变化时重算，日常不逐帧扫描资源或计算包围盒。

正常游玩时仍以盒盖正面外侧交互点检查瞄准、原版距离和遮挡，避免中心嵌墙后拒绝已露出的正面。进入查看后不再以六米可见范围维持悬浮面板，也不依赖继续瞄准。菜单／F8、受伤／治疗、传送、角色状态变化、游戏事件、原版镜头接管、角色或交互组件失效、断线和场景对象销毁都会退出，不受进入等待限制。退出立即解除自有查看与事件订阅；界面仍有效时文字和侧边渐变继续淡出，不等待淡出才交还控制，死亡或原版接管不启用失去资格的角色或覆盖新状态。界面失效、角色替换、断线、场景清理及新的原版查看接管文字区域时直接释放。独立 Tick 同时维护淡出和关闭提示清理，不依赖角色 LateUpdate 一定执行。

丢下或切换所持雕像不会结束阅读，也不修改该物品的使用资格。查看时只关闭并暂时禁用自己的手电；退出恢复原先允许的使用资格，不自动重新开灯，因此原先关闭的手电仍保持关闭，原先开启的手电需退出后手动打开。其他玩家的手电不受限制，仍可能照亮世界中的盒子模型。现有近景、宽体、倒立和画面滤镜只在正常第一人称状态生效，阅读期间停用，退出后依据当前持有物恢复；已开始的怪相自我预览被阅读打断后不续播，伪装外观仍按持有状态维护。宽体打开盒子的按键判断与交互提示共用临时降低后的镜头，判断结束先恢复自有覆盖，再进入阅读取景。

0.2.54 默认位置与旋转已采用保存的大厅挂墙记录，亮度继续可调。`DebugMode=true` 时，F8 的“模型摆放 / Model placement”页可编辑当前内置的桌游盒子：

1. 在大厅打开面板，点击“移到面前”找到模型，关闭 F8 观察。
2. 按住位置、旋转或缩放的 X/Y/Z 数值，左右移动鼠标。离按下点越近越精细，越远调整越快；回到按下点停止，松手结束。可切换“数值输入”，填写后点击“应用数值”。关闭面板、切换窗口或场景、角色对象失效时取消拖动。
3. 选择补光编号，用其下方“灯光亮度”数值按住左右拖动调节 0～5 倍亮度，或切换数值输入后应用；再点击“保存摆放”。记录保存在游戏的 `BepInEx/config/CalypsoExpansionSet/lobby-box-placement.json`，每次保存另有时间戳历史记录，BepInEx 日志也包含完整数据。
4. 调试模式下重进同一大厅会读取保存值；也可手动读取或恢复默认。正式模式使用源码默认摆放，后续位置变化仍需保存后更新默认数据。

记录包含模式版本、稳定模型 key、场景／大厅参照名称、保存时间、局部位置、欧拉旋转、三轴缩放、辅助世界坐标、`LightPreset` 和 `LightBrightness`。旧记录没有灯光字段时使用 1 号，没有亮度字段时使用 1 倍，已有坐标和方案保持。对非有限数值、越界位置、非正或过大缩放、非法亮度、错误模型／格式版本／光照编号、不同大厅参照拒绝应用。保存记录不写入原版存档，非调试模式不读取本机摆放文件。

工具当前仅支持内置盒子，不提供任意 FBX／ZIP 的运行时导入。盒子的源尺寸、材质和构建方式见 [资源说明](../Assets/LobbyBox/README.md)。

## 满配大厅测试

沿用 `DebugMode=true`、`TestRoomEnabled=true` 和 `--ces-test-room` 的现有专用单人测试入口。进入后默认按实际商店家具清单临时补齐陈设；商店管理器尚未就绪时，使用当前资源核对的七类：收音机、衣柜、镜子、舞厅设备、两种骰盒和旧钟。已有陈设保留。测试入口会进入雕像陈列房，可沿原通道返回大厅，或用已有 F8“传送”返回原版出生点。

0.2.52 曾按整个枚举补齐八类，错误地额外生成门铃。2026-10-16 核对当前游戏商店 `_furnitureItemsData`，七种商品不含 `DOORBELL`，虽然游戏保留其预制体和大厅锚点。0.2.53 起排除这种仅有资源而未入商店的类型；原场景已有铃铛不移除。运行期商店清单变化时仅撤回本功能添加且已不在清单中的类型。

“测试大厅满配”按钮只在该专用测试模式可用。关闭按钮或 DebugMode 时撤回本功能添加的陈设；断线、场景替换及卸载清理记录。原生添加／移除入口负责陈设显示，不手动移动购买落点。

该功能用于核对所有可购买大厅陈设的占位，沿用专用测试房的禁止存档写入与远端准入保护。普通房间、真实购买进度、收藏和货币不由本功能修改；不解锁无关能力或消耗品。

## 五组补光

F8 中的 1～5 每次启用一组，0／关可关闭；全部随盒子移动、旋转和缩放。正面指带图案的盒盖平面。

| 编号 | 方案 |
| --- | --- |
| 1 | 左前暖色柔和聚光 |
| 2 | 右前中性柔和聚光 |
| 3 | 正面点光漫射，兼顾侧边 |
| 4 | 左右交叉的两束宽聚光 |
| 5 | 顶侧聚光与侧面点光组合 |

均使用宽照射范围和柔和阴影。亮度跟随大厅附近一盏原版受控灯的当前输出与初始强度之比，在原版灯光更新后采样，再乘以保存的亮度倍率；0 倍关闭补光，调整倍率不会绕过停电。开关、闪烁及恢复沿用原版灯的实际表现。不改原灯具，也不启动自定义随机闪烁。中途切方案、晚创建直接读取当前亮度；找不到有效大厅灯具时保持补光关闭，面板显示等待状态。最终外观与事件联动仍需实机选择和确认。

## 实现与验证边界

`LobbyBoxRuntime` 在 `Room.GetStartRoom()` 下维护模型、正面交互点和补光，不添加网络组件。原版 `onInteract` 的 performed 事件消费按下，并配对消费释放；空上下文的服务器重试不触发盒子。`LobbyBoxInteractionUi` 借用原版近距点与按键边框图样，创建独立 Image/TMP，使用 `GetInputIndicatorText` 和 `InputIcons.SpriteAsset` 处理绑定／手柄图标；字体材质与字体自身图集配对，不复制原控件的临时子网格、遮罩和叠加层。

`LobbyBoxInspection` 管理一次本地查看，借用 `CameraManager.CliInitInspectItemCamera`／`CliSetLocalCameraState(INSPECT_ITEM)` 和 `PlayerEntity.EnabledMovement(false)`，沿用原版书本的进入顺序、准星隐藏与自身手电停用入口。打开前保存站立／蹲姿相机状态、检查相机 Follow／朝向、蹲跳锁、准星和手电使用资格，不接管所持物品；关闭、失败和异常共用幂等清理，撤销自己的写入并解除事件订阅。进入等待采用 `onStateChangeComplete`，完成后开放关闭，取消／超时则退出；回调带会话编号，旧回调不能关闭或解锁新查看。查看期间的资格检查与进入条件分开，不把主动暂停移动误判成失去控制。原版成功接管镜头后不覆盖其新状态，切换检查目标或原版控制状态前释放查看；被原版拒绝的相机请求不被前置清理改变。相机临时渲染覆盖先经 `HeldCameraOverrides.End` 逆序撤销，本功能不直接改输出相机的投影或每帧姿态。查看结束后立即释放自有控制限制，UI 在有效时独立淡出；检查相机的盒子目标保留到原版返回过渡不再使用该相机时再恢复，防止过渡起点跳到上次的书／棋盘。快速重新查看复用自己的目标并释放上次 UI；原版重新指定目标时交还，延迟清理不覆盖后来写入的目标。场景清理／卸载释放剩余相机槽点和淡出 UI。

`LobbyBoxReadingUi` 使用独立屏幕 UI，淡入／淡出时长取原版字幕的 `_fadeDuration`，非法值使用安全回退；文字和水平翻转的侧边渐变共用 CanvasGroup，同一帧多次维护只推进一次。淡出结束、界面失效或强制释放时隐藏并销毁；淡出期间仍验证原角色／场景归属。原版书本的打开动画、音效、RuleBook／InspectableElement 网络组件不移植到本地盒子。

正文子对象位于 `RectMask2D` 阅读区内，按实际换行高度和当前视口限制 anchoredPosition；屏幕尺寸、语言或原版参考字体变化时重新计算。阅读期间按既有文本刷新周期更新当前角色的原版字幕字体、字号与样式，同时刷新正文、滚动提示及固定署名；失去有效字幕来源时释放阅读 UI。滚轮读取 Input System 自身的每格单位，同一鼠标更新时间只消费一次，距离按字体行距计算，不乘帧时长、不排队缓动；移动／摇杆读取绑定动作并按时间连续推进。`LobbyBoxCredits` 在阅读区外维护固定署名，按实际字体度量适配底部高度和整行宽度；操作及滚动提示使用有下限的自动字号。自有图标纹理和 Sprite 随 UI 释放，来源见 [资源说明](../Assets/LobbyBox/README.md#制作人员图标)。

`LobbyFurniturePreview` 仅在专用测试模式、DebugMode、服务器和本机 Ready、家具管理器已启动服务器时调用 `SrvAddFurniture`。添加前记录所有权，重复维护不重复添加；恢复仅调用本功能添加项的 `SrvRemoveFurniture`。

0.2.53 用户截图确认模型和提示可见，同时暴露白块图标与介绍遮挡；0.2.54 的顶部世界介绍已被本方案替换，其历史检查不能视为新布局验收。0.2.55 完成 Release 编译与针对实际查看／取景源码的托管检查。后续用户反馈文字偏大、关闭提示重叠，以及退出镜头借用上次书／棋盘位置；0.2.56 修复镜头目标交还时机和右下角短提示，0.2.57 接续调整字号／正文区域、进入等待与淡出，0.2.58 增加阅读区裁切／滚动和固定署名，隔离手电与所持物品并修正宽体交互。当前 Release 编译及 1,977 项托管断言通过；最终滚轮手感已有用户试玩确认，详情见 DEVELOPMENT。本轮未部署或启动游戏，最终构建的镜头过渡、墙边取景、HUD／中英文排版、改键／手柄、持有其他相机效果、生命周期和多人边界仍需实机覆盖。编译、资源研究、几何计算和托管替身不能代替真实显示。
