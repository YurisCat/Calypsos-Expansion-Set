# 雕像顶部谏言

顶部谏言以短句提示雕像特征，优先采用四字双句，后续新增或修改尽量押韵、保持节奏对称。允许诙谐、夸张和谐音表达；已经确认的文案按原文保留。详细机制及参数放在使用说明和设计文档中，谏言不承担完整玩法说明。

当前文案的实现来源为各类型定义的 `ShortDescription`，单行且不超过 80 字符。名称显示开关只影响物品名称，顶部谏言继续按类型显示。

| --- | --- | --- |

| 鸭步雕像 | duck_step | 走路鸭叫，别被听到 |
| 极速雕像 | extreme_speed | 神行飞速，长驱直入 |

| 描边雕像 | outline | 黑底白线，轮廓浮现 |
