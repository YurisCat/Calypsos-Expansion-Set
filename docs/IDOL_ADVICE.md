# 雕像顶部谏言

顶部谏言以短句提示雕像特征，优先采用四字双句，后续新增或修改尽量押韵、保持节奏对称。允许诙谐、夸张和谐音表达；已经确认的文案按原文保留。详细机制及参数放在使用说明和设计文档中，谏言不承担完整玩法说明。

MOD 文案来自类型定义的 `ShortDescription`，原版文案来自 `UI/OriginalIdolAdvice.cs` 中按实际配置 ID 匹配的对照；均为单行，不超过 80 字符。开发表格中的名称简写在游戏里补全“雕像”后缀。简介仅供开发参考，不作为游戏提示。

`[UI] ShowIndividualIdolNames=true` 时显示以下正式名称；关闭时原版保留原名，MOD 统一显示“卡里普索拓展包雕像”。名称开关不影响顶部谏言。终局雕像、缺失拼图的名称未指定，两个开关状态都保留原名。
