# 诅咒状态图标

`disguise.png` 为已确认四宫格原画的左下图案，裁切并去除图片自带的灰白棋盘格背景，输出 256×256 透明 RGBA。

`disguise.rgba` 是同图逐行反转后的 RGBA32 原始像素（262144 字节，第一行为图片底部），嵌入程序集。运行期沿用已验证的 `LoadRawTextureData` 路径，不调用 `LoadImage`。调整图片后需同步重新生成原始像素。

骰子伪装和大师伪装规则共用此图，显示在原版诅咒状态栏的自有槽位中；具体生命周期见 [伪装诅咒与大师规则](../../docs/ARCHITECTURE.md#伪装诅咒与大师规则)。
