# Calypso's Expansion Set

Invokyr 的内容扩展 MOD，为游戏添加具有特殊效果的新雕像及可配置的便利功能。版本与更新记录见 [CHANGELOG](CHANGELOG.md)。

## 当前内容

- **弹跳雕像**：持有时按原力度自动连续跳跃，成功自动起跳时随机播放音效，也会产生怪物可感知的噪声。
- **近景雕像**：拿起时镜头平滑放大，放下时平滑恢复视野。
- **声控雕像**：用声音驱动前进，替代键盘与手柄的方向输入，其他动作保留；眼睛待机时红色、允许前进时蓝色，所有玩家可见。
- **倒立雕像**：画面倒立，视角双轴和左右移动反向，前后方向不变；HUD、菜单与鼠标指针正常。
- **鸭步雕像**：走路时配合脚步随机发出短叫声，附近玩家可听见，也会作为噪声进入原版怪物听觉系统。
- **极速雕像**：拿起即以五倍水平速度持续移动，蹲下、跳跃不减速，空中锁定方向，奔跑无效；支持键盘和手柄，菜单中不停，放下恢复。
- **迟钝雕像**：移动方向与松键延迟 0.3 秒，视角和交互即时。
- **接力雕像**：同一人累计持有越久，地面和空中水平移动越慢；放下暂停累积，同人再拿继续，换人接手恢复，任意两人即可交替接力。按存活人数分单人／多人两档，单人较宽松；死亡、复活及进出房间自动切档并保留疲劳。眼睛随疲劳由绿渐红，所有玩家可见。
- **疑神雕像**：持有者身上随机传出原版怪物声音，附近玩家可听见，也可能引来有听觉的怪物。
- **宽体雕像**：身体变宽、变矮，镜头降低并略微横向拉伸；原版碰撞和过门能力保持。
- **怪相雕像**：每次拿起随机变成本局已生成、待生成或待重生的一种怪物外观；其他玩家看到怪物，并看不到手持雕像、手电外观及其灯光，持有者第一人称保留雕像显示和手电照明。放下恢复，池为空时使用哭泣人偶。只改变外观，不获得怪物能力，也不改变仇恨规则。
- **像素雕像**：场景与 HUD 一起像素化，打开菜单恢复清晰。
- **描边雕像**：场景与 HUD 变为黑底白线，打开菜单恢复清晰；不透视遮挡物。
- **大头雕像**：他人眼中的角色头部变大，持有者的场景与 HUD 产生强烈鱼眼畸变；菜单正常。

弹簧雕像暂时停用，旧实例不会自动转换为弹跳雕像。0.2.30 公开稳定版曾暂停怪相，本版恢复修正后的怪相；升级后所有玩家使用同一版本并重开房间。

当前开发构建启用十四种 MOD 雕像，均带待办清单临时图案；这十四种与表内二十一种原版物件均有指向谏言，移开视线即隐藏。可在配置中开启具体名称，显示完整“XX雕像”；原版两个未指定名称的终局物件保留原名。原版普通消息出现时，谏言移到下一行；全屏旁白和菜单期间隐藏。无需开启 DebugMode；正式手绘完成后可替换临时图案。名称与文案见 [顶部谏言](docs/IDOL_ADVICE.md)。

编译、托管检查与游戏验证范围分别见 DEVELOPMENT，完整玩法与真实多人验收仍待完成；接力疲劳不写入原版存档。外观与接力玩法契约已更新，联机各端须使用匹配版本。

## 安装

需要 Windows x64 版 Invokyr 和 BepInEx 6 IL2CPP。退出游戏后，将 `CalypsoExpansionSet.dll` 放入 `BepInEx/plugins/CalypsoExpansionSet/` 或 `BepInEx/plugins/`，再正常启动游戏。联机时所有玩家都需安装兼容版本。

## 配置与 F8 调试

配置文件为 `BepInEx/config/calypso.invokyr.expansionset.cfg`。

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| [Gameplay] NaturalSpawning | true | 加入匹配的原版自然候选池，保留原版生成总数 |
| [QualityOfLife] DisableBoardPawnCollision | true | 关闭棋盘进度棋子的实体碰撞，方便移动和踢骰子；各端独立生效，联机建议一致 |
| [UI] ShowIndividualIdolNames | false | true 显示表内原版及 MOD 的完整名称；false 原版保留原名、MOD 统一显示“卡里普索拓展包雕像”；顶部谏言保持 |
| [Debug] DebugMode | false | 开启 MOD 调试模式，启用测试工具和诊断日志；不影响正常玩法 |
| [Debug] WindowKey | F8 | 打开/关闭测试窗口；None 禁用按键 |
| [Debug] TestRoomEnabled | false | 允许专用测试房启动，仍需参数与 DebugMode |

CFG 使用英文键名，说明按中文、英文分行显示；旧棋盘碰撞中文键自动迁移并保留原值，新旧键同时存在时以英文键为准。修改后重启游戏。普通游玩设 DebugMode=false，关闭测试工具和诊断日志，保留必要状态与异常日志。只关闭 F8 窗口不会关闭调试模式。

DebugMode=true 时按 F8，拖动标题栏可移动窗口；点击雕像按钮即可生成。按钮区列出全部已注册 MOD 雕像，类型较多时滚动查找。也可点击命令输入框，输入命令后按回车（含数字小键盘回车）或点击 Run 执行：

| 命令 | 操作 |
| --- | --- |
| `list` / `status` / `help` | 查看类型、状态与帮助 |
| `spawn <key>` | 房主在附近生成雕像，如 `spawn jumping`；可用 key 由 `list` 查看，每种同时最多一只手动实例 |
| `teleport` | 房主循环传送到存活的 MOD 雕像旁 |
| `teleport <key>` | 房主定位指定种类，例如 `teleport wide_body` |
| `next` | 房主跳过收集与手动投骰，随机 1–6 点推进当前棋子，沿原版事件进入下一小局；先将棋盘放在桌上 |
| `revive` | 房主复活所有已死亡且连接就绪的玩家，并为存活受伤玩家补满血；按各玩家血量上限恢复 |
| `inspect` | 仅显式单人测试房：切换角色外观检查视角，暂时停用新雕像的本地镜头效果以检查体型；再次执行恢复 |
| `visual <key> texture / white / flat` | 比较该类型便签的图案、纯白底色和逐面法线；结束时用 `texture` 恢复 |

出售/销毁手动实例后可再次生成，自然实例不占调试限额。窗口会暂停原版输入并解锁鼠标，极速仍持续移动；关闭后恢复输入。在游戏内控制正常时使用生成命令。

客户端也能打开 F8，使用查询与本地诊断；改变游戏状态的调试操作仅房主可执行。四个 DEV 按钮同排：`下一关`、`复活`、`无敌：关/开`、`传送`。复活同时为存活受伤玩家补满血，死亡房主也可操作；无敌仅切换房主自己的原版伤害免疫，关闭 DebugMode、退出会话、角色替换或死亡时释放，关闭 F8 窗口仍保留；传送将所有存活且连接就绪的玩家送回各自的原版出生点，不复活或补血。雕像生成和循环定位按钮保持原布局。

`next` 在原版 Flow 播放时拒绝新请求，已进入推进等待阶段的请求则等待 Flow 结束；保留其他基础过渡检查。独立特殊事件不一定受 Flow 覆盖，测试时仍应等待房间生成和特殊事件结束；专用陈列测试房不可用。原版事件可能保留地图，不保证每次替换全部外部房间。

## 单人测试房

退出当前游戏，在 CFG 中设定：

```ini
[Debug]
DebugMode = true
TestRoomEnabled = true
```

启动时附加 `--ces-test-room`，例如通过 Steam 启动（替换为自己的 Steam 安装目录）：

```powershell
& '<Steam 安装目录>\steam.exe' -applaunch 3883570 --ces-test-room
```

参数与两个开关必须同时满足。游戏自动开本机单人会话，在初始房门外建立陈列房并将玩家放到前方。房内陈列原版雕像和每种已启用的 MOD 雕像，不陈列 MissingPiece/Final 终局物件；MOD 展品按 key 字母顺序排列，占用各自调试限额。

测试房创建后，本机游戏相机在渲染期间按陈列房尺寸扩大视距，相连的初始房也使用该视距；正常启动不启用，原版相机配置不持久修改。

测试房禁止远端加入、骰子事件、常规怪物生成和存档写入。取走或销毁的雕像不会自动补刷；重置时退出游戏，用相同参数重启。普通游玩不附加此参数，并关闭 DebugMode。

## 构建

使用 .NET SDK 6（版本选择见 `global.json`），并准备游戏的 BepInEx、interop 程序集。默认游戏路径见工程的 `InvokyrPath`，路径一致时运行：

```powershell
.\scripts\Build.ps1
```

游戏路径不同时，指定自己的安装目录；仅编译务必传 `DeployToGame=false`：

```powershell
dotnet build .\CalypsoExpansionSet.csproj -c Release -p:DeployToGame=false '-p:InvokyrPath=D:\Games\Invokyr'
```

`Build.ps1` 仅编译，输出为 `bin/Release/net6.0/CalypsoExpansionSet.dll`。音效随源码保存在 `Assets/Audio`，依赖 DLL 不随插件分发。

本机部署可在退出游戏后运行以下脚本；它会备份旧插件并核对新 DLL 哈希，完成后正常启动游戏：

```powershell
.\scripts\Deploy.ps1 -InvokyrPath 'D:\Games\Invokyr'
```
